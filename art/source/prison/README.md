# School-prison art source

Original 8px tile geometry, drawn by `tools/gen_prison_art.py`, using the project's
approved Act 2 masonry and key color swatches copied alongside this file. No
Celeste sprites or room artwork are included. Celeste is a design reference only.

`school.png` is the editable atlas master. Runtime export is
`ldtk/art/prison/school.png`; preserve its 128×128 canvas and tile positions when
replacing artwork. Cage and door source PNGs have matching runtime basenames.
`ldtk/art/prison/atlas.json` describes the indices. Copy an edited source PNG to
its runtime location and let Godot reimport; no layout rebuild is required.

The generator recreates the original artwork and overwrites runtime images, so
keep hand edits in these source files and export them directly afterward. The
palette uses warm school masonry, turquoise windows/water and four key accents.

## Temporary scaffold pass (2026-10-06)

At the user's request, terrain slots 0–5 now reuse the existing connected steel
scaffolding generated by `tools/gen_scaffolding.py`. The shared scaffold sheet
is not modified. Background slots 16–19 are subdued blue-grey; school props,
keys, cage, and water retain their original atlas positions. This keeps the
editable layout ready for later final art without sacrificing platform clarity.
